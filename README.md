# Freelo

Платформа для фрилансеров и заказчиков — микро-биржа труда для поиска исполнителей и безопасной работы над небольшими проектами.

## Возможности

- профили исполнителей и рейтинг;
- публикация заказов и отклики;
- эскроу-счёт для безопасной сделки;
- чат между заказчиком и исполнителем;
- отзывы после завершения работы.

Проект находится в разработке. Эскроу работает в тестовом режиме, без реальных платежей.
